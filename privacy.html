Privacy policy

Last updated: [date]

What the tool accesses

  • Google Drive and Sheets (drive.file): only the files the tool creates itself (a Google Sheet, a log spreadsheet, a Drive folder and Google Docs). It cannot see any other files in the account.
  • Gmail, read only (gmail.readonly): it reads job alert emails under one label. It never deletes, labels or replies to email.
  • Gmail, send (gmail.send): it sends a short notice to its owner when a run fails. It sends no other email.

What it does with that access

It turns job alert emails and public job listings into a list of postings, writes matches into its own Sheet, and creates CV and cover letter documents in its own folder. It reads the same Sheet back to see the owner's decisions and requests.

Processing by an AI model

Posting text and the owner's career details are sent to the Google Gemini API to score each posting and draft documents. Contact details are never sent to the model. OR "The tool uses the free Gemini API tier, under which Google may use the data to improve its products."]

What it does not do

  • It does not sell or share data with third parties, apart from the AI processing described above.
  • It does not use the data for advertising.
  • It does not apply to jobs or post anything.
  • It does not access files it did not create.

Where data is kept

Results and the tool's state stay in the Google account that authorised it. The tool runs on scheduled GitHub Actions jobs that keep nothing after each run.

Removing access

Access can be removed at any time from the Google account's security settings under "Third-party apps and services". Deleting the tool's Sheet, folder and documents removes everything it created.

Google API data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
